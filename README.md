# 等等贝贝吧

一款 Godot 2D 横版追逐游戏，发布到 GitHub Pages。当前为 **2026-10-01-dev5 开发试玩**：董贝贝在学院追赶孟培杰、沿河岸启动定位铃，最后与曹钜钛完成夜市纸巾救援。孟／曹采用短发完整人物十二帧；三人跑跳比例重新校准。前三关重画九段漫画、29格剧情，使用错落分镜和画内对话气泡。尚不是商业发布候选。

## 游玩方式

根地址自动进入 [Godot 游戏](godot-demo/)，不再提供新旧版切换。历史 Canvas 模块和测试仍保留用于追溯，界面不再进入旧游戏。工程、测试与质量边界见 [Godot README](godot/README.md)。

- 自动前进；A / ← 回头，长按前进方向消耗能量加速；P / Esc 暂停或继续。
- 空格 / W / ↑ 跳跃，松开短跳；支持二段跳。下＋跳穿过单向高台。
- 手机左侧方向键、右侧跳跃键均在画面外，支持双指；电脑隐藏触控键。
- 拾取能量补充冲刺；触碰篮球自动踢向前方，第二关可击中定位铃开启桥。香蕉、巡逻车、落箱、尖刺与塌陷平台均有各自判定。
- 首页进入学院地图，点击徽章路标查看道路简介。开发试玩前三关均开放，灰色锁标是尚未制作的后续章节。地图可回看漫画或进入独立动作练习。
- 漫画自动逐格出现；点击一次显示全页，再点击继续。剧情期间玩法计时停止；地图菜单可回看漫画。
- 第三关先追两人，半途孟培杰肚子疼停下；追上曹钜钛拿纸巾后，需在 90 秒内向左跑回。返程道具与危险物不同，按住向左冲刺，曹钜钛跟在后方；返程失败可从返程起点重试。
- 星级、音效和渲染上限保存在本机浏览器；历史 Canvas 存档迁移尚未接入。存储受限时有提示，仍可游玩。
- 首页与地图的设置按钮可开关音效，选择保存在本机浏览器；关卡介绍展示道路场景。
- 追上窗口在 85% 进度开启，不是自动胜利；必须与目标实际接近。掉坑可从检查点继续，生命耗尽或返程超时失败。

## 本地运行与测试

试玩导出包可直接通过静态服务器运行：

```powershell
python -m http.server 4173
```

浏览器打开 `http://127.0.0.1:4173`。Godot 导出与完整测试见工程 README；保留的历史 JavaScript 回归：

```powershell
node --test
node tools/level-bot.mjs
node tools/campaign-bot.mjs
```

## 技术与素材

- Godot 4.7.2、GDScript、单线程 Web 导出；Web 页面采用本地 HTML/CSS/SVG，逻辑画面 1280×720。
- 物理与绘制独立；设置中 60/120 是绘制上限，实际流畅度取决于设备。
- 校园、河岸和夜市使用独立原创背景，本地 Web Audio 合成短音效。
- 仅包含根据参考制作的游戏素材，不包含用户提供的原始照片；无账号、服务器或云存档。
- 学院人物使用独立的距离驱动动画相位、显式帧矩形与脚底锚点；位置插值仅用于绘制，不改变碰撞。曹钜钛的身高比例为 183/170。
- 生成的人物动画仍需最终人工动作验收；手机实机性能与触控尚需测试。第三关为独立夜市背景，去程与返程危险布局不同。

## GitHub Pages

本项目仓库为 `Icarus122/deng-deng-beibei`。如尚未配置 Pages，在 GitHub 仓库进入 **Settings → Pages**，选择 **Deploy from a branch**，来源设为 `main` 分支和 `/(root)`。仓库没有额外的 Actions 部署 workflow，也不需要构建。

之后在本地提交并推送到 `main`，GitHub Pages 会按仓库设置发布静态文件：

```powershell
git fetch origin
git status --short --branch
git add <要提交的文件>
git commit -m "docs: update game documentation"
git push origin main
```

推送成功不等于 Pages 已完成构建；应在仓库 **Settings → Pages** 查看发布状态和网址。是否能在微信内打开还取决于用户网络对 GitHub 的访问情况。

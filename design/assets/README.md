# 学院魔法视觉样稿资源

本轮使用内置 image_gen 工具生成原创视觉概念；WebP 只进行格式压缩，不使用 Python 修改构图或角色。原始生成文件保留在工具默认保存目录。商业游戏截图只作为美术与布局参考，未作为游戏资源复制；真人参考照片不加入项目。

最终消费文件：`campaign-map-v2.webp`、`home-academy-v1.webp`、`academy-lineup-v4.webp`、`rescue-comic-v2.webp`。`campaign-map-v1.webp` 是本轮早期样稿，当前页面不使用。

这些图不是可直接替换跑步图集的动画资源。设定图中的身高是示意，正式角色站立资产以同一脚底基准将曹钜钛校准为其他两人的 183/170 倍，不能靠头发或透视制造差异。

## v0.3.0-alpha 正式素材接入

`assets/academy-beibei-v1.png`、`academy-meng-v1.png`、`academy-cao-v1.png` 为分别生成的透明 12 姿势图；`academy-poses-v1.png` 为三人的起跳、下落与坐下状态。四张实际尺寸均为 1254×1254。`assets/academy-comic-v1.webp` 为前两章六格漫画。

生成要求：严格保留本页人物设定中的发型、衣服与孟培杰眼镜；三人学院动漫风、右向侧面运动、每个角色完整独立、透明背景、无文字；跑步按左右脚接触、承重、经过、蹬地、腾空、准备落地编排，附属动作保持同一衣服。漫画使用黑底、不同宽度分格、学院场景、空白对话区，不复制参考截图的角色或构图。一次附属动作输出因裁断肢体被拒绝，没有加入仓库。

工具不能保证严格网格与专业动画一致性，因此接入时按 alpha 连通区域审查，并在 `academy-frames.js` 保存独立源矩形和锚点；不按整张宽度等分。`tools/scan-atlas.py` 只读像素，不修改图片。只进行了 PNG/WebP 格式压缩。当前部分摆臂与支撑脚轨迹仍待人工修正；不能把 12 张生成姿势等同于已验收的专业跑步循环。

# 2026-10-01 Godot 三关开发试玩交付记录

## 定位

这是新的可游玩开发版，不是计划全部品质门槛已通过的正式候选。默认 Canvas v0.3.1-alpha 保留；Godot 单独放 /godot-demo/。前三关功能已经连接，但不得据此命名 v0.4.0-alpha 或承诺 Steam 上架质量。发布核验记录会在最后补充。

## 本轮完成

首页→学院地图→道路简介→漫画→实际三关；原创长篇故事圣经、人物关系/性格、36 章容量的五幕框架与慢伏笔账本。前三关轻松日常，不提前揭露最终反派。

校园入门、河岸定位铃机关、独立夜市双追逐与纸巾限时返程。真实坡道/单向/移动/塌陷台，进入接触扣心、预警不伤人的落箱、扫掠移动障碍、真实篮球飞行/命中，检查点和独立返程补给。孟到中点停下，曹为之后的追逐目标；纸巾交接要求实际近身，不是到坐标自动成功。

完整身体素材隔离，保留原画不重画/缩放，专用起跳/落地/受伤/踢球/失败等反馈；曹单独完整站姿替代原来缺小腿的候选。170/170/183 相对身高固定，曹是白皮肤动漫学院风。

Web 原创学院地图与旗帜、道路预览、首尾及中段漫画、逐格自动显示/首次全展开/再次继续、跳过/独立回看。手机按键在 canvas 外并支持双指，长按行进方向加速；桌面隐藏触控键。暂停、后台冻结、返程重试镜头复位。音效/星级/60或120渲染上限本机保存；禁用存储会提示但不阻止游戏。

## 仍需完成的发布品质项

1. **动画仍未验收**：目前 v3 完整大步幅 12 姿势，不是120张独立原画。严格左右腿交换、自然承重/首尾和≤4世界像素脚滑没有成立的验证。多个新候选重复、串色或风格不一致，已拒用，不能用渲染帧率掩盖。
2. 所有高台入口/连接在30/60Hz、移动极值下的逐连接操作验收；目前覆盖底路整关与局部上台/下台，不是完整路线图 AI。
3. 新手/熟练玩家反馈、手机真机长帧与触控；第三关机器人有受伤/坑洞检查点回档，难度余量不是真人保证。
4. 首包未压缩 WASM 39,514,754字节 + PCK 15,308,632字节，外部漫画/UI另算，超过25MB预算；需裁剪模板/按需资源与传输验证。
5. Canvas→Godot 通关记录迁移尚未实现；Godot使用独立存档。原生界面仅文本后备，不等于Web完整UI。
6. 当前是短促合成音效，无完整配乐/混音。未来Boss/选角/技能生命差异/换装/合作是故事和玩法设计，不在本次偷偷堆进前三关。

## 执行取舍及代价

以下取舍用于保持本轮可验证；没有通过的品质项仍留在计划里，不以开发版上线销项。

- 在已有隔离 worktree 内执行，保留默认 Canvas、未跟踪旧方案和忽略的本地编辑器；代价是两套试玩并存。
- 用户明确选择完整身体后，替代被否决的拆分关节模型；不靠运行时遮挡鞋子或独立拼头补错，代价是需要完整动作原画。
- 放弃凑24帧和不合格候选，保留12个大步幅核心姿势、176px一轮；只采用安全的第4帧鞋色修订，代价是严格接触/循环仍未通过。
- 物理60Hz、渲染上限120和插值，不声称120张独立绘画或所有手机120FPS；代价是实际步态采样仍有限。
- 用用户已授权的 Python 原像素连通隔离和明确锚点重打包；不自动按墨迹拉伸，代价是原画本身的坏姿势不能被打包修好。
- 长线分五幕/36章容量，早期校园欢快，多关慢慢引出阴影；未来生命/技能数值仅假设，代价是后续剧情节点会调整。
- 用户要求无人值守全项执行后，允许先连接标明开发版的三关，同时保留动画品质门槛；代价是预览可玩但还不是发布候选。
- AI 保留选中的落脚岸，并在下降阶段二跳；空中被球击中先到达岸再停，不用放大碰撞盒，代价是上层完整路线仍需专项检验。
- 曹缺腿站姿另生成完整原画，旧图保持不变；代价是还需风格一致性验收。
- 先用原创程序音效，不加入未授权录音，代价是音频制作尚简化。
- 导出白名单、真实 PCK 启动与 Web加载验证，不把导出退出码等同于资源齐全；代价是新增依赖需同步清单，首包仍偏大。
- 沿用用户已经明确的提交/推送/Pages授权，但只发布独立开发入口；代价是仍不能把未通过动作验收的游戏称为整计划完成。

# 《等等贝贝吧》当前实现与收尾计划

> 更新日期：2026-09-20。本文记录仓库当前实现，不再沿用首版“两关低分辨率像素游戏”的旧任务清单。原始玩法和验收目标见 [设计规格](../specs/2026-09-15-deng-deng-beibei-game-design.md)。

## 项目目标

制作一款可直接部署到 GitHub Pages 的原创 2D 横版追逐跑酷游戏。玩家操控女生董贝贝，在校园到黄昏天桥的连续路线中追赶男生孟培杰。使用原生 HTML、CSS、JavaScript ES modules 和 Canvas 2D；不引入框架、构建步骤、服务端 API 或第三方运行时资源。

## 当前架构

| 模块 | 职责 |
| --- | --- |
| `game-logic.js` | 固定步长下的玩家移动、碰撞、收集、检查点、追上与失败状态 |
| `level-data.js` | 24,000px 主旅程、五个区域、手写地面节奏、高路、道具与危险数据；由区域数据派生五个独立章节 |
| `pursuer-ai.js` | 孟培杰独立移动、巡航/逃跑节奏、自己的跳跃路线与终段追逐速度 |
| `hazard-logic.js` | 施工箱、巡逻物、挡板、塌陷平台等危险的状态与碰撞处理 |
| `simulation-clock.js` | 默认 60 FPS 固定步长；检测持续掉帧后降到 30 FPS，性能恢复后回到 60 FPS |
| `game.js` | DOM 菜单、Canvas 渲染循环、输入、HUD、章节按钮与结算流程 |
| `character-renderer.js` / `scene-renderer.js` | 角色动作、高清场景绘制与背景层次 |
| `assets.js` | 区域背景 WebP 优先、PNG 回退，并按当前区域懒加载 |
| `audio.js` | 使用 Web Audio 本地合成游戏事件音效 |
| `level-progress.js` | 使用 `localStorage` 保存章节解锁、最佳进度、硬币、胜场与徽章 |

## 已实现

- [x] 玩法闭环：自动前进、A/←减速回头、D/→消耗能量主动冲刺、跳跃/二段跳、能量、金币、篮球、香蕉、弹簧、速度垫、风区、施工箱、巡逻物、挡板、塌陷平台和检查点。
- [x] 追逐规则：追上窗口在进度 85% 开启；开启时只缩短追逐间距，不直接判胜。孟培杰进入终段节奏后仍由玩家操作冲刺、道具与路线；实际接触距离不超过 56px 才胜利。提前拉开到上限或抵达终点仍未追上则失败。
- [x] 孟培杰使用独立 AI：按时间节奏巡航和加速，能自主跳上可走路线及天桥弹簧高路，不复制贝贝的跳跃输入；篮球可使他减速或短暂倒地。
- [x] 关卡编排：一个 24,000px 连续主旅程，依次为校园入口、篮球场、银杏林路、湖畔施工区、黄昏天桥；另有五个可单独游玩的区域章节。地面坑和障碍按教学、常规、加压、喘息与高潮分段手写。
- [x] 可选高路提供移动速度收益和奖励；高路连接与地面暴露宽度由测试和关卡机器人检查。
- [x] 章节菜单、胜利解锁、`localStorage` 进度、最佳表现与挑战徽章；无账号、云存档或服务端。
- [x] 高清背景裁切而不拉伸，WebP 懒加载和 PNG 回退；画面添加低干扰的动态前景层。角色以统一尺寸绘制，跑步按移动距离换帧；孟培杰保留眼镜，贝贝失败使用哭泣动作。相机无震动。
- [x] Web Audio 合成跳跃、落地、拾取、冲刺、命中、检查点与结局反馈；无外部音频文件。
- [x] 当前自动化结果：`node --test` 78 项通过；`node tools/level-bot.mjs` 的路线可达性、路段节奏与胜负基线断言通过。理想路线模拟约 120.6 秒，并在 85.4% 进度追上；这是模拟结果，不代表真人通关时长。

## 验证与发布命令

在项目根目录运行：

```powershell
node --test
node tools/level-bot.mjs
python -m http.server 4173
```

打开 `http://127.0.0.1:4173` 可本地预览。项目没有打包命令，GitHub Pages 应直接发布仓库 `main` 分支的根目录。推送前先 `git fetch origin` 并检查分支差异；若发生分叉，检查并安全整合后再推送，不要强制覆盖远端历史。
